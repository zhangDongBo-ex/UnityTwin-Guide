# UnityTwin 使用手册

在线阅读：**https://zhangdongbo-ex.github.io/UnityTwin-Guide/**

包含客户端与服务端启动、Windows 一键联调包、Luban / FairyGUI、构建、回归与常见问题，以及 UML 组件图、启动流程图、事务时序图。

支持离线阅读、图示放大、目录搜索、命令复制和打印。下载 `index.html` 后可直接用浏览器打开。

本仓库只发布使用手册。UnityTwin 项目源码与原始回归报告保留在私有仓库；手册中的相关引用需要项目访问权限。

更新：从 UnityTwin 的 `Docs/Build-Pages.cjs` 生成在线版，将 `index.html` 和 `.nojekyll` 更新到本仓库 `main` 分支；GitHub Pages 从分支根目录自动发布。
